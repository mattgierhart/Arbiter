# Naming Options — Agent Action Orchestration Plugin

## Criteria

- Communicates "agent action decision-making" not just "task management"
- Unique in Obsidian community plugin registry
- Works as a noun (the thing) and adjective ("a ___ task")
- Pronounceable, memorable, greppable
- Not already an overloaded term in AI/ML

---

## Candidates

| Name | Pros | Cons | Verdict |
|------|------|------|---------|
| **Arbiter** | Clear meaning (decision-maker), strong, short | Slightly adversarial connotation | **Recommended** |
| **Dispatch** | Action-oriented, implies routing decisions | Common word, many existing uses | Strong alternate |
| **Triage** | Implies assessment + prioritization | Medical connotation, suggests urgency only | Good but narrow |
| **Nextstep** | Literally describes the core function | Generic, forgettable | Weak |
| **Conductor** | Orchestration metaphor, implies coordination | Overused in infrastructure tooling | Decent |
| **Resolve** | Implies decision + unblocking | Sounds like conflict resolution only | Weak |
| **Runbook** | Familiar ops term, implies structured action | Already means something specific | Avoid |
| **Sentinel** | Implies watchfulness, assessment | Sounds like monitoring/security, not action | Avoid |
| **Ponder** | Implies deliberation, thinking before acting | Too passive, cute | Weak |
| **ActionFrame** | Descriptive, technical | Two words, awkward as plugin name | Weak |

---

## Recommendation

**Arbiter** — it means "one who has the authority to make decisions," which is exactly what this plugin does for agents. It's short, distinct, and works naturally in context:

- "Run through the Arbiter before executing"
- "The Arbiter recommends ASK"
- "Check the Arbiter log"
- Plugin name: `obsidian-arbiter`

**Runner-up**: **Dispatch** — more action-oriented but less unique.

---

## Naming Decision

**Status**: Decided  
**Name**: `obsidian-arbiter` — **Arbiter: Agent Action Orchestration**  
**Rationale**: "Arbiter" communicates decision-making authority. Subtitle "Agent Action Orchestration" makes the purpose obvious to both AI agents and humans browsing the Obsidian plugin registry. The full display name in the registry will be **"Arbiter — Agent Action Orchestration"**.
